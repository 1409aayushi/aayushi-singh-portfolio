# Aayushi Singh — Engineering Portfolio V2

Premium responsive static portfolio based directly on the supplied Engineering Portfolio PDF.

## Deploy to GitHub Pages
1. Create a GitHub repository, e.g. `aayushi-portfolio`.
2. Upload `index.html` and `style.css`.
3. Repository → Settings → Pages → Deploy from branch → `main` / root.
4. GitHub will provide the public URL.

## Deploy to Vercel
1. Import the repository into Vercel.
2. Framework preset: Other.
3. Build command: leave empty.
4. Output directory: `.`.
5. Deploy.

## Before publishing
- Replace the blank `mailto:` link with Aayushi's actual email.
- Add GitHub URL if desired.
- Add project/publication links where available.
- If a custom domain is used, configure it in GitHub Pages or Vercel.

No build step or JavaScript framework is required.
